PROBLEM 3: N-QUEENS OPTIMIZATION AND VARIANTS

The N-Queens problem requires placing N queens on an N×N chessboard such that:

No two queens share the same row

No two queens share the same column

No two queens share the same diagonal

(a) SEARCH SPACE ANALYSIS FOR 8-QUEENS
Brute Force Search Space (No Optimization)

Each queen can be placed in any square of the board.

Total squares on board:
8 × 8 = 64

For 8 queens:
64^8

Result:
64^8 = 281,474,976,710,656
≈ 2.8 × 10^14 possibilities

This search space is extremely large and impractical to check.

With “One Queen Per Row” Constraint

If we place exactly one queen in each row, we only choose the column position.

Choices per row = 8

Total combinations:
8^8 = 16,777,216

This greatly reduces the search space.

Considering Column Constraint (Permutation)

Each queen must also be in a different column.

So we choose permutations of columns.

Total permutations:
8! = 40,320

Estimated Backtracking Exploration

Backtracking removes invalid placements early.

Possible column permutations:
40,320

After removing diagonal conflicts, the algorithm explores roughly:
~15,000 or fewer states

Final valid solutions:
92

Thus backtracking reduces the search space from trillions to only thousands.

(b) OPTIMIZED N-QUEENS USING 1D ARRAY
Instead of storing the entire board, we store only column positions.

Board representation:

board[row] = column

Example:

board = [1,3,0,2]

This means:
Row 0 → Column 1
Row 1 → Column 3
Row 2 → Column 0
Row 3 → Column 2

Diagonal Tracking Arrays

Column array
columns[col]

Main diagonal array
diag1[row + col]

Anti-diagonal array
diag2[row - col + N - 1]

Array sizes:
columns size = N
diag1 size = 2N − 1
diag2 size = 2N − 1

PSEUDOCODE

function solveNQueens(row)

if row == N
    print solution
    return

for col from 0 to N-1

    if columns[col] == false AND
       diag1[row + col] == false AND
       diag2[row - col + N - 1] == false

        board[row] = col

        columns[col] = true
        diag1[row + col] = true
        diag2[row - col + N - 1] = true

        solveNQueens(row + 1)

        columns[col] = false
        diag1[row + col] = false
        diag2[row - col + N - 1] = false
Why this optimization works:

No need for 2D board scanning

Conflict checking takes O(1) time

Backtracking eliminates invalid states early

(c) TRACE FOR N = 4
Goal: place 4 queens on a 4×4 board.

Step 1

Place queen at:
Row 0 → Column 0

Board array:
[0, -, -, -]

Step 2

Row 1 tries columns:

Column 0 → conflict (same column)
Column 1 → conflict (diagonal)
Column 2 → valid

Board:
[0, 2, -, -]

Step 3

Row 2 tries columns:

Column 0 → conflict
Column 1 → conflict
Column 2 → conflict
Column 3 → conflict

No valid placement → BACKTRACK

Step 4

Backtrack to Row 1

Next choice:
Column 3 → valid

Board:
[0, 3, -, -]

Step 5

Row 2:

Column 1 → valid

Board:
[0, 3, 1, -]

Step 6

Row 3:

Column 0 → conflict
Column 1 → conflict
Column 2 → conflict
Column 3 → conflict

Backtrack again.

Step 7

Eventually algorithm finds first valid solution:

Board array:
[1, 3, 0, 2]

Board representation:

. Q . .
. . . Q
Q . . .
. . Q .

(d) FINDING ONLY ONE SOLUTION
Normally the algorithm finds ALL possible solutions.

To stop after the first solution:

Modify the base case.

Modified pseudocode:

function solveNQueens(row)

if row == N
    print solution
    return true

for col from 0 to N-1

    if safe position

        place queen

        if solveNQueens(row + 1) == true
            return true

        remove queen

return false
This stops the algorithm immediately after finding the first valid solution.

(e) N-QUEENS WITH FORBIDDEN SQUARES
Some squares are marked as forbidden and cannot contain queens.

Example board:

. Q . .
X . . .
. . X .
. . . .

Algorithm modification:

Before placing a queen, check whether the square is forbidden.

Updated condition:

if columns[col] == false AND
diag1[row + col] == false AND
diag2[row - col + N - 1] == false AND
forbidden[row][col] == false

Updated pseudocode fragment:

for col from 0 to N-1

if forbidden[row][col] == true
    continue

if column or diagonal conflict
    continue

place queen
solveNQueens(row + 1)
remove queen
Impact on Complexity:

Worst-case time complexity remains:

O(N!)

However:

Forbidden squares reduce valid placements.

Backtracking prunes the search earlier.

In practice, the algorithm may run faster due to fewer available positions.
